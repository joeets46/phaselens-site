# PhaseLens site

The project site for [PhaseLens](https://github.com/joeets46/phaselens), a football analytics data
platform built on StatsBomb open match data. It is a single static page (React, TypeScript, Vite,
Tailwind CSS 4) that explains the project: what it is, the dashboards it produces, the milestones
reached, and what it does not claim.

The analytics, data model and metric definitions live in the
[phaselens repository](https://github.com/joeets46/phaselens); this repo only holds the site.

## Run it

Requires Node.js 20.19 or newer (a Vite 8 requirement).

```sh
npm install
npm run dev      # dev server with hot reload
npm run build    # type-check, then build to dist/
npm run preview  # serve the production build locally
npm run lint
```

To get absolute URLs in the social-card tags (`og:image`, `twitter:image`), set the public site URL
when building: `SITE_URL=https://example.com npm run build`. Without it they are root-relative.

## How `pressure-ridges.json` is produced

The ridge landscape in the footer shows pressure events per minute for the fifteen Euro 2024 knockout
matches. `src/data/pressure-ridges.json` holds only aggregated counts (no raw events, no player data)
and is generated by `scripts/export_pressure_ridges.py` from a local checkout of phaselens:

```sh
python scripts/export_pressure_ridges.py
PHASELENS_DIR=D:\other\phaselens python scripts/export_pressure_ridges.py   # non-default location
```

The script reads phaselens read-only, counts events of type 17 (Pressure) per match, period and
minute exactly as `pressure_event_count` is defined in phaselens `docs/metric_catalog.md`, and then
reconciles the totals per match, per team and per player with phaselens's own metrics outputs. If any
number differs it stops and writes nothing. The JSON records the source commit of the open data and
the phaselens commit it was derived with.
